# CandidateVoice

Open-source candidate experience intelligence platform.

## Problem

Hiring processes lack transparency.

## Approach

Candidate-reported structured signals:
- response times
- interview stages
- communication quality
- ghosting reports

## Trust Architecture

- sample-size-aware confidence scoring
- tiered confidence (low / medium / high)
- anonymous aggregation
- human moderation before publication

## Tech

Next.js · Supabase · Vercel · TypeScript
